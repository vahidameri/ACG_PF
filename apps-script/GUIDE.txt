اطلس ACG — راهنمای اجرا روی گوگل‌شیت
=====================================

فایل‌های این بسته
-----------------
  Code.gs           سرور: شیت، دسترسی‌ها، آپلود به درایو، ایمیل‌های خودکار
  Index.html        خود اپ اطلس (یک فایل، حدود ۱.۴ مگابایت)
  appsscript.json   تنظیمات اسکریپت (مجوزها، تقویم و درایو)

همه‌ی مراحل را با حساب گوگلی انجام بده که قرار است سوپر ادمین باشد.
(کسی که setup را اجرا کند سوپر ادمین می‌شود.)


مرحله ۱ — ساخت شیت و اسکریپت
-----------------------------
 1. در Google Drive یک Google Sheet خالی بساز (مثلاً: ACG Atlas — DB).
 2. Extensions ← Apps Script. اسم پروژه: ACG Atlas.
 3. Project Settings (چرخ‌دنده) ← تیک
    Show "appsscript.json" manifest file in editor
 4. برگرد به Editor (آیکن <>):
    - Code.gs: محتوای فعلی را پاک کن، محتوای Code.gs را بچسبان.
    - appsscript.json: محتوایش را کامل با فایل appsscript.json عوض کن.
    - + ← HTML ← اسم: Index  (دقیقاً همین؛ .html را خودش اضافه می‌کند)
      محتوای پیش‌فرض را پاک کن و کل Index.html را بچسبان.
      (فایل بزرگ است؛ اگر ویرایشگر چند ثانیه کند شد صبر کن.)
 5. Ctrl+S


مرحله ۲ — ساخت تب‌ها و اسامی
----------------------------
 1. از فهرست بالای ویرایشگر تابع setup را انتخاب کن ← Run.
    Review permissions ← حسابت ← اگر «Google hasn't verified this app» آمد:
    Advanced ← Go to ACG Atlas ← Allow
 2. تابع seedDemo را اجرا کن (فقط اسامی ۱۱ نفر و ۱۱ پروژه).

 چک: تب‌های Projects, Team, Tasks, Meetings, Contracts, Config, … ساخته شده‌اند
      و در تب Team ردیف تو با ایمیلت و access = super هست.


مرحله ۳ — انتشار «داده» (API)
------------------------------
 Deploy ← New deployment ← (چرخ‌دنده) Web app
   Description:     data
   Execute as:      Me
   Who has access:  Anyone
 Deploy ← آدرسی که با /exec تمام می‌شود را کپی کن.


مرحله ۴ — وصل کردن آدرس داده
-----------------------------
 1. ته Code.gs این را اضافه کن (آدرس مرحله ۳ را جایش بگذار):

      function run1() { setApiUrl('https://script.google.com/macros/s/XXXX/exec') }

 2. run1 را اجرا کن، بعد پاکش کن و ذخیره کن.

 چک: در Execution log باید API_URL = … و GOOGLE_CLIENT_ID = … دیده شود.


مرحله ۵ — انتشار «اپ» (لینک تیم)
---------------------------------
 Deploy ← New deployment ← Web app
   Description:     app
   Execute as:      User accessing the web app
   Who has access:  Anyone with Google account
 Deploy ← این آدرس /exec «لینک اطلس» است.

 چک: لینک را باز کن ← صفحه‌ی ورود ← «ادامه با ایمیل تو» ← نمای کلی با ۱۱ پروژه.


مرحله ۶ — تنظیم اولیه داخل اطلس
--------------------------------
 1. بک‌آفیس ← افراد و دسترسی: برای هر نفر ایمیل گوگلش را وارد کن و دسترسی را چک کن
      مدیرعامل: مدیرعامل (exec)
      وحید کیوانیان، مهرزاد گلی: هد (head)
      بقیه: عضو تیم (member)
    کسی که ایمیلش ثبت نشده، وارد نمی‌شود.
 2. بک‌آفیس ← تنظیمات ← چرخه‌ی هفتگی:
      جلسه‌ی هفتگی (پیش‌فرض پنجشنبه ۱۰:۰۰)، مهلت گزارش (پیش‌فرض چهارشنبه)،
      شروع هفته، روزهای کاری.
 3. هر پروژه: مدیر پروژه، کارفرما، رابط پروژه، تاریخ‌ها، مایلستون‌ها، تخصیص نفرات.

 چک: لینک را با یک حساب ثبت‌نشده (پنجره‌ی ناشناس) باز کن ← باید «تعریف نشده است» بیاید.
      یک PM باید فقط پروژه‌های خودش را ببیند.


مرحله ۷ — ایمیل‌های خودکار (اختیاری)
-------------------------------------
 شیت را رفرش کن ← منوی ACG Atlas ← «نصب همه‌ی اتوماسیون‌ها»
   خلاصه‌ی صبح (۷:۳۰، فقط برای تو)
   یادآوری اقدام‌های معوق جلسات (۸:۱۵)
   یادآوری گزارش هفتگی (روز مهلت ساعت ۱۴ و صبح روز جلسه ساعت ۸)
 روشن/خاموش هر کدام: تنظیمات اپ. اگر نمی‌خواهی، این مرحله را انجام نده.


مرحله ۸ — ارسال لینک برای تیم (دو راه ورود)
---------------------------------------------
 لینک data (مرحله ۳)  ← ورود با کد ایمیلی: ایمیل را می‌زند، کد ۶ رقمی به ایمیلش می‌آید.
                         بدون حساب گوگل، بدون هشدار «تأیید نشده». تا ۳۰ روز وارد می‌ماند.
                         (تقویم شخصی و لینک Meet خودکار برای این افراد نیست.)
 لینک app (مرحله ۵)   ← ورود با گوگل: تقویم شخصی و Meet هم کار می‌کند.
                         بار اول یک بار اجازه‌ی گوگل لازم است (Advanced ← Go to …).
 ایمیل هر نفر باید در بک‌آفیس ثبت شده باشد. جیمیل شخصی روزی حدود ۱۰۰ ایمیل خودکار مجاز است.


قانون‌های امنیتی
-----------------
 - شیت را با هیچ‌کس به اشتراک نگذار. هر کس شیت را ببیند همه‌چیز را می‌بیند
   (قراردادها، تسک‌های خصوصی مدیرعامل). بقیه فقط از لینک اپ وارد می‌شوند.
 - لینک «داده» (مرحله ۳) را برای کسی نفرست.


به‌روزرسانی‌های بعدی
---------------------
 فایل جدید را جایگزین کن ← Deploy ← Manage deployments ← مداد ← Version: New version ← Deploy
 (هیچ‌وقت New deployment نزن؛ لینک‌ها عوض می‌شوند.)
   فقط Index.html عوض شده  ← نسخه‌ی جدید برای app
   Code.gs هم عوض شده      ← نسخه‌ی جدید برای هر دو (data و app)
 اگر بعد از به‌روزرسانی Code.gs اتوماسیون‌ها نصب بودند، یک بار دیگر «نصب همه‌ی اتوماسیون‌ها» را بزن.
